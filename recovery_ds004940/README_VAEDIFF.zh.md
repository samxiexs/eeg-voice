# vaediff：DS004940 上的 VAE + 扩散 EEG→语音

这是按 2026-10-16 提出的两条思路写的新路线，放在复原的 recovery 代码旁边，复用了其中的扩散块（`generative_recovery.py` 的 `Block`、采样器）、EEG 编码器主干（`aligned_recovery_model.py` 的 `TemporalResidual`、增广、按句子分批）和音频指标（`audio_comparison.py`）。英文版见 [README_VAEDIFF.md](README_VAEDIFF.md)。

**现在的状态：代码写完、单元测试和合成数据冒烟测试通过、DS004940 已重新下载并处理完（原始文件已逐个删除）。没有在真实数据上训练过任何模型，下面没有任何实验结果。**

## 两条思路是怎么落到代码里的

**思路 1：损失重新设计成三项加权，带硬约束，权重按结果调。** 第二阶段的总损失是

```
L = w1 · L_voice + w2 · L_text + w3 · L_diff + β · KL
```

| 项 | 是什么 | 归一化 |
|---|---|---|
| `L_voice`（音色/内容，w1） | 两部分相加：(a) EEG 编码和音频编码的分块对比（0.4 s 一块，同一时间位置，同批其他句子做负例，同一句框的 NPC/NPI 搭档不算负例）；(b) 解码器一步去噪估计的音色差：语音帧上的长时平均谱（去掉整体响度）和真实的差，单位 dB | (a) 除以 log(候选数)，随机水平 = 1；(b) 除以音色阈值 |
| `L_text`（文本，w2） | EEG 编码经注意力池化后的文本头，与冻结的 MiniLM 句向量做批内对比 | 除以 log(批大小)，随机水平 = 1 |
| `L_diff`（扩散，w3） | mel 扩散的 v 预测损失，样本按 60% EEG 编码 / 30% 音频编码 / 10% 空条件（给无分类器引导用）混合 | 原值 |
| `KL`（VAE，β 固定） | 见思路 2 | 每维每帧的 nats，有 free bits |

初值按直觉设：`w1 = 0.5, w2 = 0.2, w3 = 1.0, β = 0.05`。每 50 次更新，控制器在固定的 256 个开发集试次上量三个数（开发集的句子训练时从没出现过）：

- `voice_rank`：EEG 编码按块检索自己句子的音频编码的排名百分位（0 最好，0.5 随机），约束 ≤ 0.42；
- `timbre_db`：EEG 条件下解码器在固定噪声步（t = 200）的一步去噪估计的音色差（dB），约束 ≤ 阈值（默认取第一阶段音频路线同一量的 1.5 倍）；
- `text_rank`：文本头检索自己句子文本的排名百分位，约束 ≤ 0.45。

规则：`w1` 跟 `max(voice_rank/0.42, timbre_db/阈值)`、`w2` 跟 `text_rank/0.45`，比值大于 1（违反约束）就乘 `exp(0.5·(比值−1))` 往上调，小于 1 就往下调，单次变化截在 ±0.5 之内，总范围限制在初值的 1/4 到 4 倍；`w3` 是锚，只能手动改。每一轮写一行到 `outputs/vaediff/<run>/tune.jsonl`。

"每 50 个结果由 Claude 猜一次"的接口：在运行目录里放一个 `control.json`，训练每 50 步检查一次，文件一变就读进来：

```json
{"weights": {"voice": 0.8, "text": 0.3}, "thresholds": {"voice": {"voice_rank": 0.40}}, "mode": "hold", "note": "第 3 次猜测：文本一直不满足，先固定"}
```

`weights` 里给的值会成为新的基准；`mode: "hold"` 停掉自动规则，只用手给的权重；`"auto"` 恢复自动。训练中让 Claude 看 `bash scripts/run_vaediff.sh status` 的输出、写下一份 `control.json`，就是一轮"猜测"；改动和备注都会记进 `tune.jsonl`。这需要有人（或一个 `/loop` 会话）在训练时守着，训练本身不会去问 Claude。

**思路 2：不同人对同一段音频的 EEG 不一样，所以编码必须是分布（VAE），解码用扩散。**

```
音频  ─ WavLM-base 第 3/6/9/12 层（冻结）─ 小卷积 ─► q_a(z | 音频) = N(μ_a, σ_a²)      第一阶段训练，之后冻结
EEG   ─ 被试通道混合 + 共享时空卷积 + 被试 FiLM ─► q_e(z | EEG, 被试) = N(μ_e, σ_e²)  第二阶段
z（32 维，25 Hz）─► 条件 mel 扩散（v 预测、adaLN、CFG）─► Vocos 对数 mel ─► Vocos ─► 24 kHz 波形
```

- 两个后验共用同一个潜空间，解码器只看 `z`，不知道它来自音频还是 EEG。
- `KL(q_e ‖ N(μ_a, σ_a² + s²))`：EEG 编码的分布向句子的音频编码靠拢，但先验被放宽了一个"个体差异" `s`（默认 0.3），每个人的编码可以在句子编码附近偏开 `s` 左右而几乎不受罚，而不是被压到同一个点上。`s` 就是"不同人的 EEG 不一样"这条判断的显式参数。
- 没见过的人（被试编号 −1）走共享路径，不用被试专属的混合和 FiLM。
- 多次呈现的合并用专家乘积：精度加权的均值，保留单次的平均精度（解码器只在单次噪声水平上训练过）。

## 数据：DS004940 重新下载与处理

`app/vaediff_data.py`，一次一个被试：下载两个任务的 BDF → 预处理 → 切段存 float16 → 读回校验 → 删掉这个被试的原始文件，再下一个。刺激音频处理完也删了，24 kHz 波形存在处理后的表里。

- 预处理沿用 9 月的做法：128 个 BioSemi 通道，声明的坏道球面样条插值（坏道超过 15% 的录音整段跳过并记录），平均参考，0.5–45 Hz 带通。两处不同：降采样到 128 Hz（45 Hz 以上本来就被滤掉了）；每段连续录音按通道用自己的中位数/MAD 缩放（无监督，各划分一视同仁）。
- 两个任务（Active、Passive）都用，每人最多 2 × 400 个试次；作者剔除的 2 句（`(LD5_Eliminated)…`）不要。
- 存的是 [−0.5, 4.5) s 的段，模型默认只用 EEG [−0.25, 3.6) s、音频 [0, 3.6) s。原因：Active 任务里每句话结束后**正好 2.0 s** 就播放提示音"Did this sentence end correctly"，最短的句子 1.6 s，所以 3.6 s 以后的 EEG 可能混进对提示音的反应，而提示音的时刻直接泄露句子时长。9 月用的 4.35 s 窗口包含了这一段。只有最长的几句会被截掉结尾（句长 1.6–3.84 s）。
- 划分：402 句是 201 对（同一句框的一致/不一致结尾），**整对**分到同一个划分：161 对训练、20 对开发、20 对测试；另外从两个任务都保留下来的人里按哈希留出 3 个人，只出现在测试里（没见过的人 × 没见过的句子）。
- 处理结果（2026-10-16 01:19–02:05）：22 人、44 段录音里保留 35 段，20 人有数据；sub-006、sub-019 两个任务坏道都超过 15%，没有数据；只剩一个任务的有 sub-007、011、012、014、017。共 13,807 个试次，2.1 GB。没见过的人是 sub-004、010、022。各角色试次数：训练 9,224、开发 1,156、测试（见过的 17 人）1,151、测试（没见过的 3 人）234，没见过的人在训练/开发句子上的 2,042 个试次不用。另有 473 个试次（3.4%）峰值超过 30 个 MAD，默认剔除（`--max-peak`）。
- 分段录音（sub-004、007、012 的 Active，sub-019 的 Passive）已经核对：事件时间轴就是各段样本数的累加，跨段处没有缺口。sub-004 本身只完成了 278 句。

两条需要知道的观察（只在 sub-001 上看过，不是结论）：句子触发后的平均 ERP 最大的负波在 0.35–0.40 s，而不是通常听觉 N1 的 0.1 s；包络反向模型的延迟扫描在 +0.25 s 处最好（单试次 r 0.079，0 延迟处 0.048）。触发之后可能还有一段播放延迟。编码器是非因果的（视野约 ±2 s），固定延迟会被吸收，但比较时间精细的指标时要记住这一点。

## 怎么跑

```bash
cd recovery_ds004940
bash scripts/run_vaediff.sh test        # 单元测试 + 合成数据冒烟，约 15 秒
bash scripts/run_vaediff.sh audio       # 第一阶段，不用 EEG，约 40 分钟
bash scripts/run_vaediff.sh eeg         # 第二阶段，约 60 分钟，每 50 步调一次权重
bash scripts/run_vaediff.sh status      # 看最近的调参轮次
bash scripts/run_vaediff.sh evaluate    # 测试集评估
```

`RUN=名字` 换第二阶段的运行名，`EXTRA="..."` 追加参数（例如 `EXTRA="--spread 0.5 --w-text 0.4"`）。日志在 `logs/vaediff_<阶段>_<运行名>.log`。

检查点选择：每 500 步用 EMA 权重在 48 个开发试次上真正采样一次，按"生成的 mel 能否在开发句子里认出自己那句"（排名百分位，同句框搭档不算候选）选 `best.pt`，从不按 L1 或扩散损失选。

## 评估

`evaluate` 分"见过的人"和"没见过的人"两组，都只用测试句子：

1. 潜空间检索（音色/内容分块检索、文本检索）：零分布是每个人 × 任务内部打乱句子标签 1000 次；区间是人和句子两个方向的 bootstrap。
2. 门槛：两种检索至少一个显著好于零分布，才生成音频（`--force-audio` 可以强制，报告里会标出来）。
3. 生成：同一试次、同一份噪声下的各条件：真实 EEG、同一人同一任务时长最接近的另一句的 EEG、EEG 置零、无条件、同一句所有试次的专家乘积及其对照（另一句的专家乘积）、音频编码上限、真实 mel 经 Vocos 的上限。指标：辨认排名、STOI、MCD、包络 r、音色差；配对差都带两向 bootstrap 区间。
4. Whisper small.en 转写 40 个试次：WER 和转写文本与原句的句向量距离。
5. 每组导出 6 个试次的试听文件。

报告是 `outputs/vaediff/<run>/evaluate_best/report.md`。

## 和 9 月数字的口径差异

9 月：只用 Active，17 人，按句子划分（320/41/41，没有按句框成对），4.35 s 窗口（包含提示音反应），256 Hz，训练折归一化，HiFi-GAN 16 kHz，最好的 0.341 包络 r 是 17 次呈现平均之后的结果。现在：两个任务，句框成对划分，3.6 s 窗口，留出没见过的人，Vocos 24 kHz。两边的数字不能直接比较；同一套评估里的"真实 EEG − 错配 EEG"配对差才是可比的量。

## 没做的、没验证的

- 没有在真实数据上训练任何一个阶段，也没测过每步耗时；默认的 40 / 60 分钟是估计。
- 阈值（0.42、0.45、音色 1.5 倍）是直觉值，第一次跑完之后应该按开发集的实际水平重新定。
- 第一阶段的音频只有 322 句训练句（约 15 分钟），解码器可能记住训练句；音频上限要看开发句和测试句的数字。
- 文本编码器 MiniLM（`sentence-transformers/all-MiniLM-L6-v2`，固定版本 `1110a243`）是为文本损失新下载的，放在 `../models/all-MiniLM-L6-v2`。
