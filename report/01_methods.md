# 1. 做了什么：从 imagined-speech EEG 重建可听语音

本项目的目标是把一个人"在脑中默念"（imagined speech）时记录到的头皮 EEG，**重建**成可以听的语音，并且用这个人的声音说出来。这里的"重建"有一个严格的含义：生成语音的那条路径只能接收一个从 EEG 算出来的连续向量，再交给一个从未见过 held-out 目标的生成模型；路径上任何地方都不允许出现"先 argmax 选出一个类别或候选句子，再播放它对应的语音"。候选集合只在最后的 evaluation 里出现，用来判断生成的语音像什么。早期版本（2026-10-06 之前）其实是"classification + rendering"，即 encoder 先选出 item 再让 decoder 去说，或者直接播放检索到的句子的 TTS；2026-10-07 这一轮把两条 pipeline 都改成了真正的 reconstruction，本报告描述的就是这个最新版本（代码 commit `255d361f`，结果见 `outputs/index.html`）。

数据方面使用了三个公开的 imagined-speech EEG 数据集，并分成两条 pipeline。**Items pipeline**（`scripts/reconstruct.py`）处理小词表：Thinking Out Loud（TOL，Nieto et al. 2022，10 人，128 通道，4 个西班牙语方向词 arriba / abajo / derecha / izquierda）和 BCI Competition 2020 Track 3（BCI2020，15 人，64 通道，5 个英语短语 hello / help me / stop / thank you / yes）。**Sentences pipeline**（`scripts/sentences.py`）处理开放词表：Chisco（Zhang et al. 2024，5 人，122 通道，每人约 5,100–6,400 个 imagined 句子、总计约 6,500 个不同的中文句子、39 个 topic，每个 imagery epoch 3.3 s）。所有数据都保留 full band（0.5/1–120 Hz），因为前期分析显示 > 55 Hz 的成分（很可能包含 covert articulation 的 EMG）携带了一部分可解码信息。

整个系统由三部分组成（见 [03_framework.md](03_framework.md) 的 Figure 1）。第一部分是 **speech side**，完全由合成语音构建、不接触任何 EEG：每个 item 或句子先用 macOS `say` 由多个 TTS voice 读出（items 用 8–12 个 voice × 3 种语速，句子用 3 女 3 男共 6 个中文 voice），然后提取 HuBERT embedding（英语用 HuBERT-base，中文用 `chinese-hubert-base`，层数按"跨 voice 识别同一内容"的准确率选择），经过 centring、PCA 和 whitening 得到 CLIP space 里的 anchor $a_k$（items 是 K−1 维；句子是 16 维再加上 log duration，归一化为单位长度）。这个 speech embedding space 相当于 CLIP 里被冻结的 speech tower。同一批 TTS clip 还提供 SpeechT5 的 log-mel（decoder 的训练目标）以及 voice traits（WavLM x-vector 的均值代表 timbre 和性别，median log F0 代表 pitch）。

第二部分是 **EEG side**，每个人单独训练（within-person）。一个 trial 先做 Euclidean alignment（用该人非 held-out 的数据估计协方差并白化），再做 causal drift removal（减去之前 20–30 个 trial 的均值，只用过去的 trial），然后计算 8 个频带（1–4, 4–8, 8–13, 13–30, 30–45, 55–70, 70–90, 90–120 Hz）在每个通道上的 log-power，既包括整个 trial 的，也包括把 trial 切成 3 或 6 段后相对整段的偏差（time course）；Chisco 的特征再 PCA 到 512 维。之后由 personal linear CLIP encoder 把特征映射到 speech space：items 用双向 InfoNCE（L-BFGS 求解，可选 supervised contrast），句子用 ridge 或 run 内 trial 与句子之间的对称 InfoNCE。频带下限、drift removal、time course、weight decay 等设置都由 coordinate search 在 inner cross-validation 上选出，最好的 3 组设置的 calibrated logits 取平均（top-3 ensemble）。对 Chisco，因为每人有约 6,000 个 trial，另外实现了一个 end-to-end 的 **deep encoder**（`eegspeech/deep.py`，Figure 2）：所有人共享的 32 个可学习 sinc band-pass filter，每人每个频带 2 个 depthwise spatial filter，0.25 s 窗口、0.125 s 步长的 log-power time course，再接每人一个 linear readout，用 CLIP loss（对冻结的句子 anchor 做 cross-entropy）训练。它是 filter-bank log-power 的可学习版本，结构上参考 ShallowConvNet（Schirrmeister et al. 2017）、EEGNet（Lawhern et al. 2018）和 Défossez et al. 2023 的 subject layer。

第三部分是 **generation**。EEG side 输出的是一个连续点：items 用 calibrated posterior 计算后验均值 $c = E[a\mid \text{EEG}] = \sum_k p(k\mid\text{EEG})\,a_k$（这是 embedding 的 least-squares 估计，不做任何选择）；句子直接用 $c = z/\lVert z\rVert$。这个 content condition 和这个人的 voice traits 一起送进一个 mel diffusion decoder（v-prediction，cosine schedule，adaLN-zero blocks，类似 DiT 的 conditioning，dilated depthwise convolution 加 self-attention），用 DDIM 采样，classifier-free guidance 只作用在 content 上（items 的 guidance 由 oracle check 在 1–4 中选出，句子固定为 2），得到的 log-mel 再经 SpeechT5 HiFi-GAN 变成 16 kHz 波形。Decoder 只用语音训练：items 的 decoder 用 Dirichlet 随机生成的"合成 posterior"作为 condition（30% 是 one-hot），让它学会处理不确定的输入；句子的 renderer 每个 fold 单独训练，只用该 fold 训练集中的句子，condition 是加了随机噪声再归一化的 anchor（因为 EEG 预测的点离任何 anchor 都很远），所以 held-out 句子对 renderer 来说是完全没听过的（open-vocabulary）。15% 的训练样本使用 null content，用于 CFG 和 "prior" control。声音方面，BCI2020 和 TOL 没有录被试的声音和性别，所以每人轮流指定一个合成 voice；Chisco 按 `participants.tsv` 的性别指定一个合成 voice。Voice traits 从不来自 EEG 或身份输入。

评估协议是 within-person 的 5-fold block-wise cross-validation：第 k 折取出每个人记录的第 k 个五分之一，TOL 是按录制顺序连续的 trial，BCI2020 是完整的 cue episode（同一 cue 连续想 4 次，必须整体放在同一折），Chisco 是完整的 run（run 内 topic 成块出现）。Inner CV 采用同样的规则；held-out trial 的标签和 EEG 都不进入训练、alignment 或 drift baseline。对生成的语音，items 用三个独立的 measure 判断它听起来像哪个 item：Whisper-small 在词表中的 forced choice、到这个 voice 说每个 item 的 DTW mel-cepstral distance（MCD）、最近的 HuBERT item centroid；句子则把生成语音的 HuBERT embedding 投影回 speech space，看真句子在该 run 约 130 个候选句中的 rank percentile（chance 0.5）、top-1/top-10、duration 相关以及 Whisper 转写。声音另外评估 speaker identification、性别（F0 > 145 Hz 判为女声）和 pitch error（semitone）。每次都同时生成三个 control：**wrong trial**（同一人另一个 episode/半个 run 之外的 trial 的 EEG）、**prior**（null content，没有 EEG）、**oracle**（直接给真实 item/句子的 anchor，即 decoder/renderer 的 ceiling）。EEG 是否优于 wrong trial 按人做 Wilcoxon 检验。

在走到这个版本的过程中，有几项数据审计改变了结论，也决定了上面的协议设计。第一，跨人（cross-person）的 imagined item 解码对所有模型（linear、deep、listening pretraining、person vector）都在 chance，因此全部改成 within-person。第二，BCI2020 发布的文件顺序不是录制顺序，同一 cue 的 4 次重复几乎是 near-duplicate（≥ 55 Hz power 上最近邻是同一 item 的比例 70%，chance 19%），官方 split 也存在泄漏；按 cue episode 划分 fold 后，BCI2020 的准确率从 0.36 降到 0.23，说明之前的大部分"信号"来自重复泄漏。第三，Chisco 的 reading epoch（5 s，句子显示在屏幕上）曾被误标为 imagined，已在 store 中改正；并且 Chisco 的 run 按 topic 成块呈现（相邻 trial 同 topic 的概率 20%，打乱后 3%），所以必须整 run 留出，而 Chisco 原文献用的是随机 8:2 trial split。第四，KaraOne 因为被试自己的录音作为 voice 效果很差（性别 57%，pitch 误差 9 semitones），按要求整体移除。
